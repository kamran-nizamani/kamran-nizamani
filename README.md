```mermaid
flowchart LR
    A[Client / UI<br/>React + Tailwind] --> B[API Layer<br/>Express + Middleware]
    B --> C[Business Logic<br/>Validation & Auth]
    C --> D[(Database<br/>MySQL / MongoDB)]

    C -.->|Cache| F[(Redis / In-memory)]
```
